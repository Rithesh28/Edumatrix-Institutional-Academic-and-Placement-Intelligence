# 📖 Overview

EduMatrix is a smart institutional platform designed to simplify academic communication and enhance placement readiness using Artificial Intelligence.

The system allows administrators and faculty to manage academic circulars, notifications, and student interactions while providing students with an AI-powered assistant for academic support.

This project is being developed as a **Final Year Major Project** for the Department of Artificial Intelligence & Machine Learning.

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/Rithesh28/Edumatrix-Institutional-Academic-and-Placement-Intelligence.git
```

```
cd Edumatrix-Institutional-Academic-and-Placement-Intelligence
```

---

## Backend

```
cd backend

pip install -r requirements.txt

uvicorn app.main:app --reload
```

---

## Frontend

```
cd frontend

npm install

npm run dev
```

---

# 🐳 Docker

```
docker-compose up --build
```
